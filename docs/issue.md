## ✨ 기능 설명

인증 사용자의 정산 완료 결정일기를 목록·상세·캘린더·통계 형태로 조회하는 API를 구현합니다.

## 🎯 개발 목적

사용자가 자신의 결정 결과를 탐색하고 개별 결정의 정산 결과를 확인하며, 월별 활동과 적중 성과를 통계로 파악할 수 있도록 합니다.
